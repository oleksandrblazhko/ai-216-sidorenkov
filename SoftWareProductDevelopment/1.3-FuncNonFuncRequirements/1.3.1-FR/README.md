### Функціональні вимоги (у форматі BDD)

**Вимога 1**  
*Feature:* Отримання довідника з безпеки  
*Scenario:*  
Given користувач перебуває у польових умовах  
When він відкриває довідник  
Then система показує адаптовану до місцевості інформацію з безпеки  

**Вимога 2**  
*Feature:* Завантаження навчальних матеріалів  
*Scenario:*  
Given користувач має підключення до інтернету  
When він натискає “Завантажити матеріали”  
Then контент зберігається для офлайн-доступу  

**Вимога 3**  
*Feature:* Замовлення харчування  
*Scenario:*  
Given користувач відкрив розділ “Підтримка”  
When він обирає категорію “Харчування”  
Then система перенаправляє його до сервісу замовлення
