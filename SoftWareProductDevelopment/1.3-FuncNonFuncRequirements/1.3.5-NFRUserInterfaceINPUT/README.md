### Нефункціональні вимоги до INPUT елементів інтерфейсу користувача

1. Усі текстові поля повинні підтримувати автозбереження введених даних.
2. Поля введення імені/прізвища мають обмеження до 50 символів та не допускають цифр.
3. Поля вводу дати повинні підтримувати вибір через інтерактивний календар.
4. Усі обов’язкові для заповнення поля мають позначатися зірочкою (*) та повідомленням при помилці.
