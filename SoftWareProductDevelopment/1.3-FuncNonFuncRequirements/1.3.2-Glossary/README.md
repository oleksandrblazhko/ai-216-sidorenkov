### Глосарій термінів

**Користувач** — особа, що використовує застосунок LearnSafeEngineering у польових або міських умовах.

**Довідник з безпеки** — розділ застосунку, який містить адаптовану інформацію про правила поведінки в екстремальних ситуаціях.

**Навчальні матеріали** — електронні ресурси для підвищення кваліфікації, що можуть бути завантажені для офлайн-доступу.

**Інтерфейс підтримки** — розділ, де користувач може звернутись по допомогу або замовити додаткові послуги.

**Сервіс замовлення харчування** — зовнішній онлайн-сервіс, інтегрований у застосунок для забезпечення фізіологічних потреб користувача.
