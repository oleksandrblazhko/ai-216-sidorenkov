### Сценарій 1: Швидкість завантаження довідника

Given користувач відкриває довідник
When система завантажує контент
Then завантаження триває не більше 2 секунд


### Сценарій 2: Доступність у темній темі

Given користувач увімкнув темну тему
When відкриває матеріал
Then всі елементи інтерфейсу залишаються читабельними


### Сценарій 3: Надійність збереження сертифіката

Given користувач завершив навчальний курс
When система формує сертифікат
Then файл зберігається у форматі PDF без помилок
