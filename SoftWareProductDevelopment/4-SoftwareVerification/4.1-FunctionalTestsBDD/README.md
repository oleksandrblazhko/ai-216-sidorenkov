### Сценарій 1: Перегляд довідника

Feature: Користувач переглядає довідник

  Scenario: Відображення адаптованого довідника
    Given користувач знаходиться у польових умовах
    When відкриває розділ "Безпека"
    Then система показує відповідну локалізовану інформацію


### Сценарій 2: Завантаження навчального матеріалу

Feature: Завантаження матеріалу

  Scenario: Успішне завантаження PDF-файлу
    Given користувач має доступ до матеріалів
    When натискає "Завантажити"
    Then файл завантажується на пристрій


### Сценарій 3: Запит на підтримку

Feature: Надіслати запит

  Scenario: Успішне створення запиту
    Given користувач відкрив меню "Підтримка"
    When вводить тип запиту та натискає "Надіслати"
    Then система створює новий запис у базі даних
