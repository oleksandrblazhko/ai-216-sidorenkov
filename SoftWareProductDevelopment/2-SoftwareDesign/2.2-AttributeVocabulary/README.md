### Словник атрибутів об’єктів

#### Клас: Користувач

| Атрибут | Тип        | Одиниці      | Опис                       |
|---------|------------|--------------|----------------------------|
| id      | Integer    | –            | Унікальний ідентифікатор   |
| ім’я    | String     | –            | Ім’я користувача           |
| email   | String     | –            | Адреса електронної пошти   |

#### Клас: Довідник

| Атрибут | Тип    | Одиниці | Опис                          |
|---------|--------|---------|-------------------------------|
| id      | Integer| –       | Ідентифікатор розділу         |
| тема    | String | –       | Назва теми                    |
| опис    | Text   | –       | Короткий зміст довідника      |

#### Клас: Матеріал

| Атрибут     | Тип    | Одиниці | Опис                        |
|-------------|--------|---------|-----------------------------|
| id          | Integer| –       | Ідентифікатор матеріалу     |
| тип         | String | –       | Наприклад, PDF, відео       |
| посилання   | URL    | –       | Посилання на файл           |

#### Клас: Сертифікат

| Атрибут | Тип     | Одиниці | Опис                            |
|---------|---------|---------|---------------------------------|
| id      | Integer | –       | Ідентифікатор сертифіката       |
| курс    | String  | –       | Назва курсу                     |
| дата    | Date    | yyyy-mm-dd | Дата видачі сертифіката     |

#### Клас: Запит на підтримку

| Атрибут | Тип     | Одиниці | Опис                          |
|---------|---------|---------|-------------------------------|
| id      | Integer | –       | Ідентифікатор запиту          |
| тип     | String  | –       | Категорія запиту (питання/скарга) |
| статус  | String  | –       | Стан обробки (новий/закрито)  |
