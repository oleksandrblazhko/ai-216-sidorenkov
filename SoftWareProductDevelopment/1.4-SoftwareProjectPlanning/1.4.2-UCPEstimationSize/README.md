### Оцінка трудомісткості (Use Case Points)

Оцінювання розміру проєкту здійснюється за методикою Use Case Points (UCP), яка враховує:
- кількість акторів;
- складність прецедентів;
- технічні та екологічні фактори.

Для проєкту LearnSafeEngineering:
- Кількість акторів: 1 (інженер-дослідник)
- Прецеденти: 3 (перегляд довідника, завантаження навчального контенту, замовлення послуг)
- Складність: середня (Medium)
- Приблизна трудомісткість: 50–70 людино-годин

Детальне оцінювання з формулами буде виконано в наступному етапі планування.
